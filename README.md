Sunset Cover Studio turns your own photos and a caption into multi-panel, poster-style cover art with bold extruded lettering and a Vice-sunset or neon colour grade, exported as a PNG at 1920 x 1080, 1080 x 1350 or 1080 x 1080. It runs entirely in the browser, offline, and your photos never leave your machine.

## Run it

```sh
node serve.ts
```
